# crunch_numeric_array_variable validations

    Invalid crunch_numeric_array_variable
    x `label` must be <character> (got a list)
    x `description` must be <character> (got a number)
    x `notes` must be <character> (got a <formula> object)
    x `path` must be <character> (got a function)
    x Invalid crunch_numeric_variable
      x Can't convert `x` <character> to <double>.

---

    Invalid crunch_numeric_array_variable
    x Invalid inferred axis structure
      x All columns must be of the same type

---

    Invalid crunch_numeric_array_variable
    x Invalid inferred axis structure
      x Second dimension of component arrays must exactly match
